# Image Enhancement Homework

## Requirements
- Python
- OpenCV
- NumPy
- Matplotlib
- scikit-image
- pandas

## Installation

python src/HW1-Assignment.py

1. Baseline
2. Contrast Stretching
3. Histogram Equalization
4. Gamma Correction
